# 外部 EEPROM BSP 适配层

设备参数上层仍只接收 `rbsp_device_param_backend`。外部 EEPROM 适配层接收板级
注入的 `read`、`write`、`erase_or_fill` 回调、双页几何和一块显式镜像缓冲区；
它不实现 I2C、SPI、地址宽度、写周期轮询或任何厂商协议。

Kconfig 默认选择内部 Flash。只有显式选择外部 EEPROM 时，固件构建才加入适配
层且不再预留内部 Flash 双页；关闭设备参数时两种后端均不链接，也不占静态 RAM。
外部后端所需镜像由启用它的板级实现显式提供，因此占用量等于两页区域且可审计。
Flash 布局门禁同样识别外部后端，此时设备参数内部 Flash 保留区为零；测试目录
提供 F103 外部后端编译配置，专门验证该裁剪和链接路径。

初始化会完整读取介质。每次填充或写入后都会回读并核对；回调失败时会尝试重新
同步镜像，重同步失败则使映射不可用，按失败关闭处理。适配器成功只证明软件回调
契约成立，不代表任何实体 EEPROM、总线或掉电行为已通过验收。

当前 Studio 正式工程 schema 尚未开放后端选择，仍固定生成默认内部 Flash；对应
接入项记录在 `TODO.md`，避免界面在没有板级 EEPROM 实现时生成不可启动的固件。
